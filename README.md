# SQL Exercises answers for sql-academy
URL is https://sql-academy.org
## File Structure
For file `answers/{id}.sql` url is `https://sql-academy.org/{lang}/trainer/tasks/{id}`. It is an answer to problem.

For file `errors/{id}.sql` url is the same, but it is original query with error, for find error type exercises.
## Example
For file `139.sql` urls are:
- `https://sql-academy.org/en/trainer/tasks/139`
- `https://sql-academy.org/ru/trainer/tasks/139`

## Interesting example:
`errors/208.sql` -> `answers/208.sql`
